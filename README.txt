FIGHTTIME EXPANDED DRAGON FATALITY ADD-ON

Requires FightTime v0.88.0 or newer.

1. Extract this ZIP.
2. Upload the included "public" folder to the root of the FightTime repository.
3. Allow GitHub to merge it with the existing "public" folder.
4. Commit the files and wait for GitHub Pages to redeploy.

The game detects the add-on automatically when the FATALITY code is activated.
If these files are absent, FightTime safely uses the standard dragon fatality.
